一句话简介：aiscan 生态常见故障的根因与处置速查，覆盖 workflow、面板、认证、限流四类问题。

核心能力
  • 面板无数据 → docs/history/ 为空 → 手动 Run workflow；确认 PATROL_TOKEN / GITHUB_TOKEN Secret 存在

  • 徽章 404 badge not found → shields 动态类型名写错（dynamic/json 非 dynamic/users）
